History of Linux

📜
Origins

Linux came from the Unix family — a free and open-source operating system developed by Linus Torvalds in September 1991 while he was a student at the University of Helsinki, Finland.

Linux File System Hierarchy

🗂️
📌 Core Concept
In Linux, everything is a file — hardware, processes, network sockets. All files live in a single-rooted, inverted tree structure starting from / (root).
/ (root)
├──/rootSuperuser's home directory. Only root can access this.
├──/homeHome directories for all non-root users (e.g., /home/joy)
├──/binEssential user binaries: ls, cd, cp, mv, rm, cat, grep, etc.
├──/sbinSystem binaries for admin: iptables, reboot, fdisk, ifconfig, swapon
├──/etcAll configuration files: /etc/passwd, /etc/shadow, /etc/fstab, /etc/hosts
├──/devDevice files: /dev/sda (hard disk), /dev/tty1 (terminal), /dev/null
├──/varVariable data: /var/log (logs), /var/mail, /var/tmp, /var/lib
├──/tmpTemporary files — cleared on every reboot. World-writable.
├──/usrUser-installed software & libraries: /usr/bin, /usr/lib, /usr/local
├──/optOptional third-party software (e.g., Docker, custom tools)
├──/bootBoot loader files: GRUB, Linux kernel images (vmlinuz)
├──/mntTemporary mount point for file systems (manual mounts)
├──/mediaAuto-mounted removable media: USB drives, CD-ROMs
├──/procVirtual FS — kernel & process info: /proc/cpuinfo, /proc/meminfo
└──/sysVirtual FS — hardware/kernel interface (sysfs)

File & Directory Operations

📁
mkdir — Create Directories
bash
mkdir /shubham              # Create single directory
mkdir dev qa test           # Create multiple directories at once
mkdir -p /dev/qa/test/devops # Create nested path (parents too)
mkdir /student{1..10}        # Create student1 to student10
mkdir -v /newdir            # Verbose — prints what was created
touch — Create Empty Files
📌 Note
touch creates empty files. It also updates the timestamp of existing files. You cannot write data with touch — use echo or vim for that.
bash
touch notes                 # Create a single empty file
touch python java react     # Create multiple files
touch books{1..10}          # Create books1 to books10
echo "Hello World" > file.txt # Create file WITH content
echo "More text" >> file.txt # Append content to file
cp — Copy Files & Directories

Syntax: cp [options] source destination

-r  # Recursive (for directories)
-v  # Verbose output
-f  # Force (overwrite without prompt)
-i  # Interactive (confirm before overwrite)
-p  # Preserve timestamps & permissions

# Copy a file
cp -rvf /root/anaconda-ks.cfg /home

# Copy all files starting with 'D'
cp -rvf /root/D* /home

# Copy an entire directory
cp -r /source/dir /dest/dir
mv & rm — Move & Remove
# Move a file/directory
mv /home/shub/file /root/Desktop

# Rename (mv is used for renaming too)
mv dev devops

# Delete file or directory
rm file.txt
rm -rvf /india/pune

# Remove an empty directory
rmdir /emptydir

# Remove directory & all contents
rm -rf /directory
⚠️ Danger
rm -rf / deletes the entire system with no recovery. Always double-check paths!

# ── PASSWORD ─────────────────────────────────────
passwd shub                  # Set/change user password

shub:$s$!1bc25f%:18002:0:99999:7: : :

grep shub /etc/passwd        # Check user account info

# ── SWITCH & LOGOUT ─────────────────────────────

Group Management

👥
💡 What is a Group?
A group is a collection of user accounts. Admins use groups to manage permissions for multiple users at once. Instead of assigning permissions to each user individually, assign to a group — all members inherit that permission.
Group Commands
# ── CREATE & DELETE ──────────────────────────────
groupadd ibmgrp              # Create a new group
groupdel ibmgrp              # Delete a group

# ── INSPECT ──────────────────────────────────────
grep ibmgrp /etc/group       # Check group properties
ibmgrp:x:1001:ajay,vijay,sachin
grep ibmgrp /etc/gshadow     # Check group admin info

# ── MEMBERS ──────────────────────────────────────
gpasswd -a ajay ibmgrp       # Add single member to group
gpasswd -M rahul,virat,rohit ibmgrp # Add multiple members
gpasswd -d virat ibmgrp      # Remove member from group
gpasswd -A sachin ibmgrp     # Make user a group admin

# ── USING usermod ────────────────────────────────
usermod -g ibmgrp shub       # Set primary group
usermod -aG ibmgrp shub      # Add to secondary group (keep existing)

# ── CHECK USER GROUPS ────────────────────────────
groups shub                  # List groups for a user
id shub                      # Full UID/GID/groups info

chmod — Change Permissions
# ── CHECK PERMISSIONS ────────────────────────────
ls -l /notes.txt
-rw-r--r--. 1 root root 0 Jan 4 14:59 /notes.txt
ls -ld /dev           # Check directory permission

# ── SYMBOLIC MODE ────────────────────────────────
chmod u+r /notes.txt   # Add read to owner
chmod u+x /script.sh   # Add execute to owner
chmod g+rw /notes.txt  # Add read+write to group
chmod o-r /notes.txt   # Remove read from others
chmod a+x /script.sh   # Add execute for ALL (u+g+o)
chmod u=rwx,g=rx,o= /file # Set exact permissions

# ── NUMERIC MODE ─────────────────────────────────
chmod 755 /shub         # rwxr-xr-x (most common for dirs)
chmod 644 /file.txt      # rw-r--r-- (most common for files)
chmod 700 /private       # rwx------ (only owner can access)
chmod 777 /public        # rwxrwxrwx (everyone full access)
chmod 600 ~/.ssh/id_rsa  # rw------- (SSH key — required!)
chmod -R 755 /webdir    # Recursive — apply to all inside

# ── OWNERSHIP ────────────────────────────────────
chown ajay /notes.txt          # Change owner
chown ajay:ibmgrp /notes.txt   # Change owner AND group
chown -R ajay:ibmgrp /dir     # Recursive ownership change
chgrp ibmgrp /notes.txt        # Change group only
Special Permissions
PermissionSymbolNumericUse Case
SUID (Set UID)s (on owner x)4xxx e.g. 4755Run file as file owner (e.g. /usr/bin/passwd)
SGID (Set GID)s (on group x)2xxx e.g. 2644Inherit group for new files in directory
Sticky Bitt (on other x)1xxx e.g. 1755Only owner can delete their files (e.g. /tmp)
 
chmod u+s /usr/bin/myprogram   # Set SUID
chmod g+s /shared/dir          # Set SGID
chmod +t /tmp                  # Set Sticky Bit

Access Control List (ACL)

🛡️
💡 Why ACL?
Standard Linux permissions only support one owner and one group. ACL lets you grant specific permissions to any user or group on any file — without adding them to the file's group.
ACL Commands (getfacl / setfacl)
# ── CHECK ────────────────────────────────────────
getfacl /devops              # View all ACL permissions on a file/dir

# ── USER ACL ─────────────────────────────────────
setfacl -m u:shub:rwx /devops   # Grant shub read+write+execute
setfacl -m u:shub:r-- /devops   # Grant shub read-only
setfacl -x u:shub /devops        # Remove all ACL for shub

# ── GROUP ACL ────────────────────────────────────
setfacl -m g:shubgrp:rwx /devops # Grant group permissions
setfacl -x g:shubgrp /devops     # Remove group ACL

# ── RECURSIVE ────────────────────────────────────
setfacl -Rm u:shub:rwx /devops   # Apply ACL recursively

# ── REMOVE ALL ───────────────────────────────────
setfacl -b /devops               # Remove ALL ACL permissions

# ── DEFAULT ACL (for new files in a directory) ───
setfacl -d -m u:shub:rw /shared  # New files auto-inherit this ACL

GREP & Regular Expressions

🔍
📌 What is GREP?
GREP = Global Regular Expression Print. It searches file(s) for a pattern and prints matching lines. One of the most powerful and frequently used commands in Linux.
grep — Complete Reference
# ── BASIC SEARCH ─────────────────────────────────
grep root /etc/passwd          # Search 'root' in one file
grep root /etc/passwd /etc/group # Search in multiple files

# ── OPTIONS ──────────────────────────────────────
grep -i Root /etc/passwd       # Case-insensitive search
grep -r root /                 # Search recursively through all files
grep -v root /etc/passwd       # Invert — show lines WITHOUT 'root'
grep -c root /etc/passwd       # Count matching lines
grep -n root /etc/passwd       # Show line numbers with matches
grep -l root /etc/passwd /etc/shadow # Show filenames that MATCH
grep -L root /etc/passwd /etc/shadow # Show filenames that DON'T match
grep -w root /etc/passwd       # Match whole word only
grep -A 3 root /etc/passwd     # Show 3 lines AFTER match
grep -B 3 root /etc/passwd     # Show 3 lines BEFORE match
grep -C 3 root /etc/passwd     # Show 3 lines AROUND match

# ── ANCHORS (Regex) ──────────────────────────────
grep ^root /etc/passwd         # Lines STARTING with 'root'
grep bash$ /etc/passwd         # Lines ENDING with 'bash'
grep '^$' file.txt              # Match empty lines

# ── EXTENDED REGEX (egrep / grep -E) ─────────────
grep -E 'root|admin' /etc/passwd  # Match 'root' OR 'admin'
grep -E 'ro{2}t' /etc/passwd      # Match 'root' (2 o's)
grep -E '[0-9]+' /etc/passwd      # Match one or more digits

# ── REDIRECT OUTPUT ──────────────────────────────
grep root /etc/passwd > /mnt/find.txt # Save results to file
grep -r 'error' /var/log/ | less   # Pipe to pager

Find Command

🎯
find — Complete Reference
# ── BY NAME ──────────────────────────────────────
find /home -name shub.txt        # Find exact filename
find /home -name "*.txt"         # Find all .txt files
find /home -iname "*.TXT"        # Case-insensitive name search
find / -name "*.conf"            # Find all config files

# ── BY TYPE ──────────────────────────────────────
find /home -type f               # Files only
find /home -type d               # Directories only
find /home -type l               # Symbolic links only

# ── BY PERMISSION ────────────────────────────────
find / -perm 4755               # SUID permission files
find / -perm 2644               # GUID permission files
find / -perm 1755               # Sticky bit files
find / -perm /4000              # Any SUID files

# ── BY USER/GROUP ────────────────────────────────
find / -user root               # Files owned by root
find / -group shubgrp           # Files owned by group
find / -nouser                  # Files with no owner (deleted user)

# ── BY SIZE ──────────────────────────────────────
find /tmp -size -10M           # Files LESS than 10MB
find /tmp -size +10M           # Files MORE than 10MB
find /tmp -size +1G            # Files larger than 1GB

# ── BY TIME ──────────────────────────────────────
find / -mtime -7               # Modified in last 7 days
find / -mtime +30              # Modified more than 30 days ago
find / -newer file.txt         # Files newer than file.txt

# ── ACTION ON RESULTS ────────────────────────────
find /tmp -name "*.log" -delete  # Find and delete log files
find / -name "*.txt" -exec cat {} \; # Execute command on each result
find / -empty                   # Find empty files and directories

tar Commands — All Formats
# ── PLAIN TAR (no compression) ───────────────────
tar -cvf /mnt/backup.tar /var      # Create
tar -xvf /mnt/backup.tar            # Extract to current dir
tar -xvf /mnt/backup.tar -C /root/Desktop/ # Extract to specific dir
tar -tvf /mnt/backup.tar            # List contents (no extraction)

# ── GZIP (.tar.gz) ───────────────────────────────
tar -cvzf /mnt/backup.tar.gz /var  # Create with gzip
tar -xvzf /mnt/backup.tar.gz       # Extract gzip

# ── BZIP2 (.tar.bz2) — better compression ────────
tar -cvjf /mnt/backup.tar.bz2 /var # Create with bzip2
tar -xvjf /mnt/backup.tar.bz2      # Extract bzip2

# ── XZ (.tar.xz) — best compression ─────────────
tar -cvJf /mnt/backup.tar.xz /var  # Create with xz
tar -xvJf /mnt/backup.tar.xz       # Extract xz

# ── UTILITY ──────────────────────────────────────
du -sh /var                        # Check original size
du -sh /mnt/backup.tar.gz          # Check compressed size
💡 Compression Comparison
gzip — Fastest, decent compression. bzip2 — Slower, better compression. xz — Slowest, best compression. For daily backups use gzip; for long-term storage use xz.

Sudo Command

🔑
📌 What is sudo?
sudo = "superuser do" — allows a permitted user to execute commands as root (or another user) without switching to the root account. Configuration lives in /etc/sudoers.
/etc/sudoers — Configuration
# ── ALWAYS edit sudoers with visudo (safe editor) ─
visudo                           # Opens /etc/sudoers safely

# ── SYNTAX ────────────────────────────────────────
# user  HOST=(run_as_user) command
root    ALL=(ALL) ALL             # Root can do anything
amir    ALL=(ALL) ALL             # Grant 'amir' full sudo
amir    ALL=(ALL) NOPASSWD: ALL   # sudo WITHOUT password prompt

# ── GROUPS (prefix with %) ────────────────────────
%punegrp  ALL=(ALL) ALL           # All members of punegrp get sudo
%sudo     ALL=(ALL) ALL           # Default sudo group (Ubuntu)
%wheel    ALL=(ALL) ALL           # Default sudo group (RHEL/CentOS)

# ── RESTRICT TO SPECIFIC COMMANDS ─────────────────
amir    ALL=(ALL) /usr/bin/systemctl  # Only allow systemctl
amir    ALL=(ALL) /usr/bin/apt        # Only allow apt

# ── WHEEL GROUP (RHEL/CentOS shortcut) ───────────
useradd shub
passwd shub
gpasswd -a shub wheel             # Add to wheel = instant sudo
# Or:
usermod -aG wheel shub

# ── VERIFY ────────────────────────────────────────
sudo -l                           # List your sudo permissions
sudo -l -U shub                  # Check another user's sudo perms
sudo whoami                       # Should output: root

Networking (RHEL/CentOS)

🌐
Network Diagnostic Commands
# ── CHECK IP ─────────────────────────────────────
ifconfig                   # Show all interface IPs (older)
ip addr                    # Modern equivalent
ip addr show ens33         # Show specific interface
ip route                   # Show routing table
ip link                    # Show network interfaces

# ── CONNECTIVITY ─────────────────────────────────
ping 8.8.8.8               # Test internet connectivity
ping -c 4 google.com        # Ping 4 times then stop
traceroute google.com      # Trace the route to host
nslookup google.com        # DNS lookup
dig google.com             # Detailed DNS query
ss -tulnp                  # Show listening ports
netstat -tulnp             # Same (older command)

# ── FIREWALL ─────────────────────────────────────
firewall-cmd --state       # Check firewall status
firewall-cmd --list-all    # List all rules
firewall-cmd --add-port=80/tcp --permanent  # Allow port 80
firewall-cmd --reload      # Reload firewall rules
nmcli — Network Manager CLI
# ── SHOW ─────────────────────────────────────────
nmcli con show                    # List all connections
nmcli con show --active          # Active connections only
nmcli con show "citynet"          # Details of specific connection
nmcli dev status                  # Device status

# ── CREATE ───────────────────────────────────────
nmcli con add con-name "citynet" ifname ens33 type ethernet \
  ipv4.add 192.168.0.2/24 gw4 192.168.0.1 ip4.dns 192.168.0.1 \
  connection.autoconnect yes ipv4.method manual

# ── MODIFY ───────────────────────────────────────
nmcli con mod "citynet" ipv4.add 192.168.0.100
nmcli con mod "citynet" gw4 192.168.0.254
nmcli con mod "citynet" ipv4.dns 8.8.8.8,8.8.4.4

# ── ACTIVATE / DEACTIVATE ────────────────────────
nmcli con up "citynet"             # Activate connection
nmcli con down citynet             # Deactivate connection
nmcli con delete citynet           # Remove connection profile

# ── HOSTNAME ─────────────────────────────────────
hostname                           # Show current hostname
hostnamectl set-hostname it.citynet.com  # Set hostname permanently

# ── TEXT UI ──────────────────────────────────────
nmtui                             # Interactive TUI for networking

# ── CONFIG FILES LOCATION ────────────────────────
ls /etc/NetworkManager/system-connections/  # All connection profiles
systemctl restart NetworkManager   # Restart after manual file edits
